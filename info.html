How to Use the Dashboard

1. Loading Resources

Paste a YouTube link into the resource bar on the main page and press Load.

2. Panic Screen

Press Esc at any time to instantly switch to the Google Classroom style panic screen.

3. Returning Home

Type back to return to the dashboard.

You can also refresh the page to reset everything.

4. What's Coming

This dashboard is planned to grow into a larger student resource hub with additional tools and features.
